# URL로 붙는 클라이언트 (ChatGPT 커넥터 등)

로컬 명령 대신 MCP 엔드포인트 URL을 받는 클라이언트는 서버를 HTTP로 띄웁니다.

```bash
python3 saemaul_mcp_server.py --transport http --port 8765
```

엔드포인트는 `http://127.0.0.1:8765/mcp` 입니다. 레거시 SSE만 받는 클라이언트는
`--transport sse` 로 띄우고 `http://127.0.0.1:8765/sse` 를 씁니다.

이 주소는 **그 컴퓨터 안에서만** 열립니다. 웹에서 도는 ChatGPT는 내 PC의 localhost에 닿지 못합니다.
웹 클라이언트에서 쓰려면 외부에서 닿는 HTTPS 주소로 열어야 합니다.

- 잠깐 시험만 할 때: `cloudflared tunnel --url http://127.0.0.1:8765` 같은 터널
- 계속 쓸 때: 서버에 올리고 리버스 프록시로 HTTPS 종단

외부에 열 때 주의할 점입니다.

- 모든 도구가 **읽기 전용**이고 자료는 공개 자료입니다. 쓰기나 삭제를 하는 도구는 없습니다.
- 그래도 아무나 쓰게 두면 그 서버의 대역폭과 CPU를 쓰게 됩니다. 접근 제한을 거십시오.
- `--host 0.0.0.0` 은 꼭 필요할 때만 쓰고, 그 앞에 프록시를 두십시오.
